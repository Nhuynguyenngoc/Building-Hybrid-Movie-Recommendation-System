# INSTRUCTIONS FOR USING PROJECT FILES

This document provides a guide to running the movie recommendation system project contained within this Jupyter Notebook file (.ipynb).


## Data Files: The project utilizes three data files:

ratings200k.csv: User ratings for movies.
tmdb_5000_movies.csv: Information about the movies: titles, genres, release dates, etc.
tmdb_5000_credits.csv: Data regarding movie credits, such as cast and crew.
Note: Ensure these files are in the same directory as your Jupyter Notebook for seamless execution.


## Code Execution:

Platforms: This .ipynb file can be executed on various platforms supporting Jupyter Notebooks, such as:

Google Collab
Jupyter Notebook
Visual Studio Code
Steps:

Upload to Platform: Upload the .ipynb file and data files to your chosen platform.
Runtime Selection (Optional): Consider selecting a suitable runtime type (e.g., GPU or TPU) for faster computations, especially when dealing with large datasets or complex models.
Run Code Cells: Execute the Python code cells in sequence. This includes data loading, Exploratory Data Analysis, preprocessing, model training, evaluation, and recommendation generation steps.
